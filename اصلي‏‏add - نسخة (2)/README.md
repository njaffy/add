# ⚡ منصة تيليجرام المتكاملة (Telegram Adder & Scraper Pro Suite)

منصة متطورة ومكتملة لإدارة حسابات تيليجرام، سحب الأعضاء (Scraping) من المجموعات والقنوات، وإضافتهم آلياً بنظام التناوب الذكي (Round-Robin) مع لوحة تحكم ويب تفاعلية لحظياً.

---

## 🌟 الميزات الرئيسية

1. **إدارة الحسابات المتعددة (Multi-Account Management):**
   - ربط عدد غير محدود من حسابات تيليجرام عبر `API ID` و `API HASH`.
   - دعم كامل لتسجيل الدخول الآمن، بما في ذلك التحقق بخطوتين (2FA Password).
   - ميزة **فحص صحة الحسابات** للتأكد من حالة الاتصال وصلاحية الجلسات بضغطة زر.

2. **سحب واستخراج الأعضاء (Member Scraper):**
   - سحب الأعضاء من أي مجموعة أو قناة عامة/خاصة.
   - **فلاتر ذكية متقدمة:**
     - استخراج الأعضاء المتفاعلين فقط (نشط مؤخراً / متصل الآن).
     - استبعاد البوتات والحسابات الوهمية.
     - تصفية أصحاب المعرفات فقط (`@username`).
   - إمكانية نقل الأعضاء المستخرجين مباشرة إلى قائمة الإضافة أو تصديرهم كملف `.txt`.

3. **محرك الإضافة الذكي (Smart Multi-Account Adder):**
   - **نظام التناوب (Round-Robin):** توزيع عمليات الإضافة بالتساوي بين الحسابات لتقليل الحمل وتجنب الشبهات.
   - **حماية الحسابات من الحظر:**
     - تحديد حد أقصى للإضافة لكل حساب (مثلاً 20 عضو لكل حساب ثم يدخل في فترة راحة تلقائياً).
     - تأخير زمني عشوائي بين عمليات الإضافة (مثلاً بين 15 و 25 ثانية) لمحاكاة السلوك البشري.
   - **التعامل الذكي مع القيود (Flood Handling):** عزل أي حساب يتعرض لتقييد فوري (`PeerFlood`) ومتابعة العملية بباقي الحسابات دون توقف.
   - **حفظ واستئناف التقدم (Pause & Resume):** إمكانية إيقاف العملية مؤقتاً أو استئنافها لاحقاً من آخر عضو تم التوقف عنده دون تكرار.

4. **لوحة تحكم وتحليلات حية (Live Dashboard):**
   - واجهة Dark Mode عصرية متوافقة مع الهواتف والشاشات الكبيرة تدعم اللغة العربية بالكامل.
   - شريط تقدم مئوي وعدّادات حية (تمت الإضافة، أعضاء مسبقاً، تخطي، فشل، حسابات مقيدة).
   - شاشة طرفية (Terminal Console) ملونة تسجل كل خطوة لحظة بلحظة مع إمكانية حفظ أو مسح السجل.

## 🚀 التثبيت والتشغيل

### 1. تثبيت المتطلبات:
تأكد من تثبيت بايثون (Python 3.9+)، ثم نفذ الأمر التالي في مجلد المشروع:
```bash
pip install -r requirements.txt
```

### 2. تشغيل السيرفر:
```bash
python app.py
```

### 3. فتح لوحة التحكم:
افتح متصفح الويب وتوجه إلى:
```
http://127.0.0.1:5000
```

## 🔑 كيفية الحصول على API ID و API HASH

1. توجه إلى موقع تيليجرام الرسمي لتطوير التطبيقات: [https://my.telegram.org/apps](https://my.telegram.org/apps)
2. سجّل الدخول برقم هاتفك وأدخل رمز التحقق الذي سيصلك داخل تطبيق تيليجرام.
3. اختر **API development tools**.
4. املأ بيانات التطبيق الجديد (أي اسم تريده في خانة App title و Short name).
5. انسخ **App api_id** و **App api_hash** واستخدمهما في خانة تسجيل الحساب داخل لوحة التحكم.

## 🛡️ نصائح وتوصيات لتجنب حظر الحسابات (Anti-Ban Rules)

> [!IMPORTANT]
> منصة تيليجرام تفرض قيوداً صارمة على إضافة الأعضاء العشوائية. للحفاظ على حساباتك وأرقامك، التزم بالتعليمات التالية:

1. **عمر الحساب:** استخدم حسابات قديمة وموثوقة (أكثر من شهرين إلى 6 أشهر). تجنب استخدام أرقام جديدة تم إنشاؤها للتو لأن تيليجرام يقوم بتقييدها بسرعة.
2. **حد الإضافة لكل حساب:** لا تتجاوز **20 إلى 30 عضواً** لكل حساب يومياً. اترك الحساب يرتاح 24 ساعة قبل إعادة استخدامه.
3. **التأخير الزمني:** اضبط فترة التأخير العشوائي بين **15 إلى 30 ثانية** على الأقل، ولا تستخدم تأخيراً قصيراً (مثل ثانية أو ثانيتين).
4. **صلاحيات الإشراف:** من الأفضل رفع الحسابات المضيفة كمشرفين (Admins) داخل المجموعة الهدف ولديهم صلاحية "إضافة أعضاء"، لأن الحسابات المشرفة تكون قيودها أخف بكثير من الأعضاء العاديين.
5. **استهداف المتفاعلين:** استخدم فلتر "سحب المتفاعلين فقط" لتفادي إضافة حسابات محذوفة أو غير نشطة قد تبلغ عن المجموعة.
